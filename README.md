# DUE

**Stop chasing customers for money.**

Track receivables and automate professional payment follow-up for freelancers and small service businesses (NGN-first).

## Slices included
1. Receivables core (auth, business, customers, invoices-as-receivables, payments, dashboard)
2. Durable reminder engine (schedule, worker, demo provider)
3. Email via Resend behind MessagingProvider (live send optional)

## Quick start
```bash
npm install
cp .env.example .env
npm test
npm start
```

See `docs/DEVELOPMENT.md` and `docs/PRODUCT_CONSTITUTION.md`.
